# CodeEX - Ageixtic IDE Changelog

All notable changes to CodeEX will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-11

### Added
- Initial release of CodeEX - Ageixtic IDE
- Based on VSCodium (VS Code OSS)
- Custom branding with CodeEX identity
- **Ageixtic Core Extension** - Ollama AI integration
  - AI chat panel
  - Code explanation
  - Code refactoring
  - Documentation generation
  - Model selection
  - Chat history
- **Quota Manager Extension** - Token usage tracking
  - Daily/monthly/total limits
  - Usage dashboard
  - Session history
  - Status bar indicator
- **Session Protector Extension** - Workspace state preservation
  - Auto-save sessions
  - Restore editors, terminals, breakpoints
  - Session management UI

### Technical
